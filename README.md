# Cari & Kenali Belanjawan 2027

Permainan carian visual dalam Bahasa Melayu. Padankan 16 gambar kecil dengan orang dalam ilustrasi, kemudian ketik padanannya.

## Cara bermain

- Setiap pusingan memilih 16 sasaran daripada 39 pilihan yang disemak: empat watak besar, enam watak sederhana dan enam watak kecil. Subjek sama tidak dipilih dua kali dalam satu pusingan; pilihan tepat pusingan terdahulu diberi keutamaan lebih rendah.
- Cari mana-mana sasaran, atau pilih satu kad gambar untuk menumpukan carian. Pemilihan kad tidak mendedahkan lokasi.
- Kesemua 16 kad muat dalam grid 4 × 4. Panel berada di sisi pada desktop dan di atas pada telefon.
- Seret untuk bergerak, cubit dua jari atau gunakan roda tetikus dan butang + / − untuk zum. Butang Muat skrin memulihkan paparan penuh.
- Pemasa lalai satu minit; pilihan Tanpa had masa tersedia. Pertukaran tetapan masa memulakan pusingan baharu selepas pengesahan.
- Empat tekaan salah dalam lima saat menghentikan tekaan selama 2.2 saat. Pemasa terus berjalan.
- Selepas pusingan tamat, Lihat jawapan menandakan lokasi mengikut nombor kad. Main lagi memilih sasaran baharu.

## Fail aktif

- `index.html`: antara muka permainan.
- `visual-targets.js`: gambar rujukan, kawasan jawapan dan kumpulan subjek; koordinat piksel pada ilustrasi 1437 × 1094.
- `visual-game.js`: carian, pemilihan rawak, pemasa, zum, input sentuh dan kaunter sedia ada.
- `visual-game.css`: susun atur desktop dan mudah alih.
- `community-search.webp`: ilustrasi komuniti yang diluluskan untuk cabaran cari orang. Gambar rujukan dipotong daripada imej ini pada kanvas pelayar.
- `landing.html`: menu permainan dan kaunter pengunjung sedia ada.

Fail `data.js`, `game.js`, `style.css`, `hotspots.json`, `bubble-transcript.txt`, `index_v1.html` dan `version2.html` ialah bahan versi terdahulu dan tidak digunakan oleh permainan aktif.
