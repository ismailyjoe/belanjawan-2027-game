# Cari & Kenali Belanjawan 2027

Permainan Bahasa Melayu: lima objek rawak, petunjuk terapung yang boleh dialih/dikecilkan, zum/pan, cubit dua jari, pemasa pilihan lima minit, maklum balas dan skrin tahniah. Buka `index.html`; tiada pemasangan diperlukan.

## Kandungan

- `bubble-transcript.txt`: transkripsi visual teks dalam ilustrasi asal, bukan pengesahan dasar Belanjawan.
- `hotspots.json`: kawasan jawapan dalam peratusan imej suntingan.
- `illustration.png`: versi gelembung dibuang dengan bantuan AI. Kedudukan utama dikekalkan tetapi beberapa butiran halus/teks kedai berubah. Semakan editorial masih disyorkan.

Sumber: folder Drive yang dibekalkan pemilik projek, fail `Program Yakin MADANI Backdrop - Perak@10x-100.jpg`, 11340 × 8647. Karya asal tidak dilesenkan semula oleh projek ini.

## GitHub Pages

Muat naik kandungan folder ini ke akar repositori. Settings → Pages → Deploy from a branch → main → /(root) → Save.

## Semakan

Semakan sintaks JavaScript lulus. Ujian pelayar desktop: lima jawapan betul, kemajuan, skrin tahniah, pusingan baharu dan pemasa. Paparan 390 × 844: tetingkap petunjuk, pengecilan dan butang zum diuji. Ujian pada peranti sentuh fizikal dan cubit dua jari masih belum dilakukan.
